| Judul ide | **Prediksi Tingkat Risiko Banjir Berdasarkan Curah Hujan dan Ketinggian Wilayah Menggunakan Pendekatan Machine Learning dan Deep Learning** |
| SDG & target yang dipilih | **SDG 11:** Kota dan Permukiman yang Berkelanjutan (Target 11.5: Mengurangi jumlah korban dan dampak ekonomi akibat bencana, termasuk bencana yang berkaitan dengan banjir). <br/> **SDG 13:** Penanganan Perubahan Iklim (Target 13.1: Memperkuat ketahanan dan kapasitas adaptasi terhadap bahaya terkait iklim dan bencana alam). |
| Masalah nyata yang diangkat | Banjir merupakan salah satu bencana yang sering terjadi akibat tingginya curah hujan serta kondisi geografis wilayah, seperti ketinggian tanah dan kemampuan drainase. Wilayah dengan curah hujan tinggi dan ketinggian yang rendah cenderung memiliki risiko banjir lebih besar. Kurangnya informasi mengenai tingkat risiko banjir dapat menghambat upaya mitigasi dan kesiapsiagaan masyarakat. Oleh karena itu, diperlukan pendekatan Machine Learning dan Deep Learning untuk memprediksi tingkat risiko banjir berdasarkan data curah hujan dan kondisi wilayah sehingga dapat membantu memberikan informasi awal dalam proses mitigasi bencana. |
| Tugas ML (Target & jenis tugas) | - **Jenis Tugas:** Klasifikasi Multikelas menggunakan data tabular. <br/> - **Target Prediksi:** Tingkat Risiko Banjir dengan tiga kategori, yaitu Rendah, Sedang, dan Tinggi. <br/> - **Fitur Prediksi:** Curah hujan, ketinggian wilayah, kelembapan, kondisi drainase, dan faktor lingkungan lainnya yang tersedia dalam dataset. |
| Objective & metrik utama | - **Objective:** Menghasilkan model yang mampu mengklasifikasikan tingkat risiko banjir secara akurat serta meminimalkan kesalahan prediksi, terutama kesalahan dalam mengidentifikasi wilayah berisiko tinggi sebagai wilayah berisiko rendah. <br/> - **Metrik Utama:** F1-Score (Macro), Recall (khususnya pada kelas risiko tinggi), Precision, dan Accuracy. F1-Score Macro digunakan untuk mengevaluasi performa seluruh kelas secara seimbang, sedangkan Recall digunakan untuk mengukur kemampuan model dalam mengenali wilayah yang benar-benar berisiko tinggi. |
| Dataset (sumber, URL, ukuran, jenis data) | **Sumber:** Dataset publik dari Kaggle, yaitu Flood Prediction Dataset. <br/> **URL:** https://www.kaggle.com/datasets/naiyakhalid/flood-prediction-dataset <br/> **Fitur Utama:** Data curah hujan, kondisi topografi, ketinggian wilayah, kelembapan, dan faktor lingkungan lainnya sesuai dengan ketersediaan fitur pada dataset. <br/> **Jenis Data:** Data tabular dalam format CSV. <br/> **Ukuran Data:** Menggunakan seluruh data yang tersedia pada dataset, dengan jumlah sampel disesuaikan berdasarkan hasil pemeriksaan dan preprocessing data. |
| Rencana tiga model (baseline / advanced / deep learning) | 1. **Baseline Model: Logistic Regression** sebagai model pembanding awal untuk mengetahui kemampuan klasifikasi menggunakan pendekatan sederhana. <br/> 2. **Advanced ML: Random Forest / XGBoost** untuk mempelajari hubungan non-linear antarfitur serta meningkatkan kemampuan prediksi berdasarkan kombinasi berbagai variabel. <br/> 3. **Deep Learning: Multilayer Perceptron (MLP)** dengan minimal 2–3 hidden layers untuk mempelajari pola dan hubungan kompleks antarfitur pada data tabular. Model akan menggunakan teknik regularisasi seperti Dropout untuk membantu mengurangi risiko overfitting. |
| Risiko & pertimbangan etika (bias, privasi) | - **Risiko Model (False Negatives):** Model dapat memprediksi wilayah berisiko tinggi sebagai wilayah berisiko rendah sehingga berpotensi menyebabkan keterlambatan mitigasi dan meningkatkan dampak bencana. Oleh karena itu, Recall pada kelas risiko tinggi menjadi perhatian utama. <br/> - **Bias Data:** Ketidakseimbangan jumlah data pada setiap kategori risiko banjir dapat menyebabkan model lebih dominan memprediksi kelas dengan jumlah sampel terbanyak. Penanganannya dapat dilakukan melalui class weighting atau teknik penyeimbangan data. <br/> - **Privasi:** Penelitian menggunakan data cuaca dan geografis yang bersifat agregat tanpa melibatkan informasi pribadi penduduk. <br/> - **Keterbatasan Model:** Hasil prediksi merupakan informasi pendukung untuk mitigasi awal dan bukan pengganti sistem peringatan dini resmi dari instansi terkait. |
